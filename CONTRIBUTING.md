# Contributing

This is an Apple Silicon macOS Rust/[nsh](https://nsh.dev) application. The primary development surfaces are Software, Databases, and HTTPS. The [product scope](docs/product-scope.md) and [acceptance matrix](docs/resources-acceptance.md) define current behavior; the separate system-service inspector remains supported.

Keep software source checks exact: Node.js, Java (macOS arm64 JDK distributions from the JetBrains JDK catalog), MySQL, Redis, and MongoDB use verified archives; Python delegates to uv’s managed interpreter catalog and installation store; PostgreSQL uses a Homebrew core formula and exact keg/receipt checks. Preserve instance data, task leases, rollback, cancellation, and explicit authorization for CA trust and privileged proxy listeners. Rule domains are fixed to `<name>.devbase.localhost`, so nothing edits the hosts file. The HTTPS editor saves a whole `Domain → Local port` rule table; it does not own application processes. The Cloudflare tunnel only creates, updates, and deletes `devbase-*` Workers it recorded in state; keep the API token out of `state.json`, logs, and argv. Tunnel tests use a fake Cloudflare API base (`TunnelService::with_api_base`), never a real account.

Run focused tests for changed behavior, then `cd app && cargo test`, the same `cargo test`, `cargo clippy --all-targets -- -D warnings` and `cargo fmt --check` gates in `app/crates/devcore`, `app/crates/devproxy` and `app/crates/devcli`, `cd app && nsh build`, Python script tests, and the third-party notice check. `cd app && nsh package --target macos` builds the ad-hoc app. Real system-trust and Chrome checks need a signed App on a disposable Mac and must not be replaced with mock results. See [verification](docs/development-verification.md).

Keep third-party licenses and notices with packaged components. Do not record real machine credentials, database content, private file paths, or certificate material in test fixtures, logs, screenshots, or documentation.

Runtime and database-location tests are described in [the implementation verification record](docs/development-runtimes-and-data.md). Preserve uv’s standard storage and project/virtual-environment precedence. External database data must retain its owner token and directory identity. Remove never erases it; external permanent deletion is deliberately unsupported. Never pass a custom data path into the app-root deletion transaction.
